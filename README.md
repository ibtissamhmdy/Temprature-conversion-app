# Temperature Conversion App

A simple JavaScript project that converts temperatures between Celsius and Fahrenheit.

## Portfolio-ready website

This repository now includes a polished GitHub Pages landing page for the app.

## Live demo

https://ibtissamhmdy.github.io/Temprature-conversion-app/

## Run locally

Open `index.html` in a browser, or serve the project with a local web server.

## Project files

- `index.html` — portfolio-style site entry page
- `styles.css` — custom layout and design
- `script.js` — conversion logic
- `05 Temperature conversion program.html` — original app version
- `05 Temperature conversion program.css` — original styling
- `05 Temperature conversion program.js` — original logic

## GitHub Pages

After enabling Pages in the repository settings, use the root folder (`/`) as the publishing source.
